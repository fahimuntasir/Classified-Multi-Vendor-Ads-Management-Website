# Thesis technology stack and website notes

## 1. Project overview

I completed the *Classified Multi-Vendor Ads Management Website* as my undergraduate graduation project at Hubei University of Technology in 2023. The thesis presents the system requirements, design diagrams, website features, and development approach for a classified-advertisement platform.

## 2. Technologies described in the thesis

The submitted thesis identifies the following tools and technologies:

| Area | Technologies described in the thesis |
| --- | --- |
| Front end | HTML, CSS, JavaScript, Bootstrap 4 |
| Back end | PHP, Laravel |
| Database | MySQL; phpMyAdmin discussed as an administration tool |
| Development and design | Visual Studio Code, Figma, Adobe Photoshop |

These details appear in the thesis, particularly Sections 3.5.2, 4.1.2, and 5.1. The list describes the thesis's chosen technology stack; it is not a claim that this repository contains a verified, runnable Laravel codebase.

## 3. Available website materials

The surviving website files reviewed for this repository include WordPress, the Classima theme, and plugin-based components. These files do not establish exactly when each component was used or changed, and they do not verify a separate Laravel implementation. I therefore keep the thesis's documented technology stack separate from the available website files rather than presenting either as proof of the other.

The public repository contains the final thesis, screenshots, and diagrams. It does not distribute the complete application files, database, private configuration, or licensed third-party software.

## 4. Documented website features

The saved screenshots show the following interface flows:

1. Browsing classified ads and filtering by search terms, categories, or location.
2. User registration and account-related screens.
3. Submitting advertisements with product information and pricing.
4. Viewing and managing existing advertisements.

These are features visible in the saved project materials, not the results of a new live-site test.

## 5. System diagrams

- **Use Case Diagram:** User roles and their interactions with the system.
- **Entity–Relationship Diagram:** Logical database design presented in the thesis.
- **DFD Level 0:** Overall system context.
- **DFD Level 1:** Major data flows and processes.
- **DFD Level 2:** More detailed process flow.

The diagrams document the thesis design. They are not presented as verified representations of the internal tables or code of any third-party website software. All five diagrams can be found in the [README](../README.md#system-design-diagrams).

## 6. Scope and source availability

This repository is an academic project archive, not a ready-to-run software release. Rebuilding and testing the original website would require the appropriate application files, database, configuration, and any properly licensed dependencies. These materials have not been included in this public repository.
